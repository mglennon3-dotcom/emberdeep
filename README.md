# Emberdeep

A text-based, D&D-style dungeon crawl that runs in the browser and installs as an app.

Pick one of twelve classes, build a party whose loyalty you have to earn, make roll-dependent
choices that follow you through a three-chapter campaign, find mythic weapons, and decide the
fate of three crowns.

## Play
Once GitHub Pages is turned on, the game lives at:
https://mglennon3-dotcom.github.io/emberdeep/

On a phone, open that link and use **Add to Home Screen** to install it. After the first visit it
works offline. Progress saves in the browser you play in.

## Files
- `index.html` – the whole game
- `manifest.webmanifest`, `icons/` – app name and icons for installing
- `sw.js` – caches the game for offline play
- `.nojekyll` – tells GitHub Pages to serve the files as they are
